Dialog 对话框

对话框用于中断用户流程，展示重要信息或请求决策。干净克制的设计语言，无彩色装饰条；遮罩采用半透明深色搭配模糊效果，营造层次感与聚焦感。

基础确认 Basic Confirm

标题 + 描述 + 取消/确认按钮，按钮默认居右

确认删除项目？

此操作将永久删除项目及其所有数据，删除后无法恢复。请确认您的操作。

表单对话框 Form Dialog

带输入框的新建对话框，用于收集用户输入

新建项目

创建一个新项目，填写基本信息后即可开始。

警示对话框 Warning

危险操作图标徽章 + 警示色边框，按钮居左以突出危险操作

删除工作区

此操作将永久删除工作区 "生产环境" 及其中所有项目、数据和成员权限。此操作不可撤销。

设置对话框 Settings

取消 + 应用 + 确定 三按钮布局，适用于偏好设置场景
